# Patricia Leonard — Art

Statische Website (HTML/CSS/JS, kein Build-Schritt nötig).

## Lokal ansehen

```bash
open index.html
```

## Struktur

- `index.html` — Seite
- `style.css` — Styles
- `script.js` — Interaktivität
- `artworks-data.js` — Werke-Daten
- `Images/` — Bilder

## Deployment

Gehostet auf Cloudflare Pages. Framework preset: **None**, kein Build-Command, Publish directory: `/`.
